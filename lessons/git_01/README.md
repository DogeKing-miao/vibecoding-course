# git_01: Git 基础实操

本 lesson 用于测试学生对 Git 基础命令和提交流程的掌握情况。

## 学习目标

学生需要理解并能够实际完成：

1. 使用 `git clone` 拉取课程仓库。
2. 使用 `git checkout -b` 创建自己的分支。
3. 修改指定 lesson 文件。
4. 使用 `git add` 暂存修改。
5. 使用 `git commit` 创建提交。
6. 使用 `git push` 推送到远程仓库。

## 分支要求

学生必须创建如下格式的分支：

```text
student/<github_username>/git_01
```

示例：

```text
student/alice/git_01
```

## 提交要求

commit message 必须包含：

```text
finish git_01
```

## 评审方式

自动评审不会检查学生本地实际输入过哪些命令，而是检查学生最终提交到 GitHub 的结果是否符合要求。

评审内容包括：

1. 分支名是否正确。
2. 是否提交了本 lesson 要求的文件。
3. 是否没有修改禁止修改的系统文件。
4. commit message 是否符合要求。
5. 答案文件是否有有效内容。
